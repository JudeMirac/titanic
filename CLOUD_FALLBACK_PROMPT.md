# Fallback when custom roles are unavailable

The lead should read AGENTS.md and keep the same project-specific boundaries. Report that named-role loading is unverified or unsupported by the current surface.

When explicit model selection is supported, use GPT-6 Luna with high reasoning for exploration and routine scoped edits, and GPT-6.1 Sol with medium reasoning for complex engineering and independent review. Otherwise report the model limitation and continue with the available model without claiming the configured routing is active.

Use at most three concurrent specialists and normally only one or two. Keep assignments independent and avoid overlapping writers. Begin with a read-only assessment, then implement only the user's authorized work. This fallback does not change tools, permissions, authentication, or available models.
